# Volumes privados de recuperação

As partes devem ficar nesta pasta com seus nomes originais. `manifesto.json` registra SHA-256 de cada parte, do ZIP combinado e dos arquivos originais. Use `../restaurar.py`; não execute arquivos desconhecidos extraídos de outros repositórios.

As partes contêm modelos ativos, vídeos, transcrições e estado dos lotes do projeto. Nenhuma credencial é incluída. Os ambientes de pacotes e executáveis de terceiros são reinstaláveis e não são copiados.
